## Descripción del curso

Este curso proporciona a los participantes los conocimientos necesarios para comprender, desarrollar e implementar soluciones modernas basadas en Inteligencia Artificial utilizando Python, integrando fundamentos de ciencia de datos, Machine Learning, Procesamiento de Lenguaje Natural (NLP), modelos de lenguaje de gran escala (LLMs) y arquitecturas avanzadas de IA Generativa.

Durante el curso, los participantes trabajarán con herramientas y tecnologías actuales utilizadas en el desarrollo de aplicaciones inteligentes, abordando desde la preparación y representación de datos hasta la integración de modelos generativos mediante APIs, frameworks especializados, agentes inteligentes, arquitecturas Retrieval Augmented Generation (RAG) y despliegue de soluciones de IA.

El programa combina conceptos fundamentales con enfoques aplicados para brindar una visión integral del ciclo de desarrollo de soluciones basadas en Inteligencia Artificial modernas.

### Objetivo del curso

Utilizar librerías especializadas de Python para análisis, procesamiento y visualización de datos.

Comprender los fundamentos del aprendizaje automático supervisado y no supervisado.

Aplicar técnicas de Procesamiento de Lenguaje Natural (NLP).
Representar información textual mediante técnicas vectoriales y modelos de embeddings.

Comprender la evolución y funcionamiento de los modelos modernos de lenguaje.

Identificar los componentes principales de la arquitectura Transformer.
Integrar aplicaciones empresariales con modelos LLM mediante APIs y SDKs.
Aplicar técnicas de Prompt Engineering para optimizar la interacción con modelos generativos.

Utilizar frameworks especializados para construir aplicaciones basadas en LLMs.

Diseñar flujos con agentes inteligentes y sistemas multiagente.
Implementar arquitecturas Retrieval Augmented Generation (RAG).
Aplicar estrategias de evaluación, trazabilidad y observabilidad en soluciones de IA.

Conocer alternativas para el despliegue escalable de aplicaciones inteligentes.


### Dirigido a

Este curso está dirigido a profesionales de tecnología, desarrolladores, científicos de datos, analistas, ingenieros de software, arquitectos de soluciones y personal técnico interesado en desarrollar, integrar o administrar soluciones basadas en Machine Learning e Inteligencia Artificial Generativa. 

Para un mejor aprovechamiento del curso se recomienda contar con: 

- Conocimientos básicos o intermedios de programación con Python.
- Familiaridad con estructuras de datos, funciones y manejo de librerías.
- Conocimientos generales de análisis de datos.
- Conceptos básicos de estadística.
- Experiencia básica trabajando con ambientes de desarrollo como Jupyter Notebook, VS Code o similares.
- Conocimientos generales sobre APIs  servicios web.
